Scan → choose

Notifications announce

Card click or Enter opens the overview with that item selected. Open Session is a separate action and never bubbles into card navigation. No Details or Clear buttons, and no C shortcut. Popup expiry is paused in this illustration.

The overview manages attention

Click an item or select it and press D for Details. Open Session remains a separate action. C dismisses the current items without a separate Clear all button. After clearing one item in Details, focus returns here; holding C cannot turn that single-item action into Clear all.

Details acts on one item

C dismisses only the inspected item. Enter or Open Session targets that item directly. Privacy hides every metadata field, while panel-only reveal leaves notifications private. All actions here are local simulations; Reset examples restores the demonstration.
