Aperture / panel UX study 02

Three compact directions, aligned to stock Omarchy.

The current panel works but reads as a self-contained app — framed cards, a custom SVG hero mark, and its own rhythm. Stock Omarchy plugins (network, audio, power) share a leaner grammar: a flat hero, icon-led flat rows, and Nerd Font glyphs. These three options close that gap so Aperture feels like part of the OS.

Top three panel directions

All three keep Aperture's NOW / NEXT / AMBIENT judgment and single "Focus OMP session" action. They differ in density and how closely they mirror stock row anatomy.

What changed vs. today

Align to stock Omarchy

  • Replace per-row BorderSurface cards with flat, icon-led rows (network scan-list pattern)
  • Fold AMBIENT into a single summary header line by default
  • Keep PanelHero flat — no framed card behind it
  • Reserve hover-revealed trailing "↵" affordance for NEXT rows
  • One keyboard footer line, caption size, 50% opacity

Icon guardrails

  • One stable silhouette in calm and attention states; only color changes
  • Single-color rendering from theme tokens (no hard-coded fills)
  • Legible at 16 px; the gap stays lower-right, clear of the count badge
  • Avoid bell / robot / sparkle / six-blade shutter / loading-spinner rhythm
  • Match Nerd Font optical weight if placed beside glyphs like 󰤨
Static design study. No external fonts, scripts, or assets. Use the state, theme, and badge controls to inspect each direction under production constraints. Direction 01 is recommended: it is the closest match to the stock network panel's anatomy while preserving Aperture's NOW/NEXT/AMBIENT judgment and single focus action.
